# Parley v0.2.0 — what you can open now

**Run:** `make install` (or `make run`) — Parley opens with new sidebar items under *Học*.
**Evidence:** [verification.md](verification.md) · stories in `docs/stories/` · screenshots in `docs/screenshots/`.

| Screen | What it does | Screenshot |
| --- | --- | --- |
| Tiến độ | XP per skill per day, daily goal, streak 🔥, 12-week heatmap | `progress.png`, `progress-empty.png` |
| Luyện nghe | dictation and shadowing on the real audio of your meetings (or 187 sample sentences) | `listening*.png` |
| Hội thoại AI | 10 role-plays with the on-device model; each turn corrected with a Vietnamese tip | `conversation*.png` |
| Luyện viết | 12 prompts A2–C1; corrected text, explained mistakes, estimated level, history | `writing*.png` |
| Đọc hiểu | 8 graded passages, select any word to look it up, questions with explanations | `reading*.png` |
| Từ vựng → Nhập / Xuất | CSV/TSV from Anki or Excel; CSV export | `vocabulary-import.png` |
| Cài đặt → Nhắc học | daily reminder only when the goal isn't met | `settings.png` |
